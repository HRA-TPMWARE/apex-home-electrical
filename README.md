# Apex Home & Electrical website

Static multi-page site prepared for GitHub Pages.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example `apex-home-electrical`).
2. Upload everything in this folder to the repository root.
3. In GitHub: Settings → Pages → Deploy from branch.
4. Choose `main` and `/ (root)`.
5. Initially test using the generated `github.io` address.
6. Only after the site is approved, configure `www.apexhomeelectrical.co.uk` as the custom domain and update DNS with your domain provider.

`CNAME` is already included for `www.apexhomeelectrical.co.uk`.

## Important before switching the live domain
- Add the final logo and real project photography.
- Current SEO focus: lighting, consumer unit changes, kitchen rewires, appliance installation and repairs.
- Confirm every service statement and certification claim.
- Connect a proper form endpoint if desired.
- Add/verify Google Search Console after DNS cutover.
- Preserve or redirect any old URLs that Google already indexes.
